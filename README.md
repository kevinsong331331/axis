# AXIS Perps

纯 JavaScript、HTML、CSS 的 Hyperliquid 永续合约终端。静态服务器根目录为 dist。

## 功能
- BTC、ETH、SOL、HYPE，主网及测试网。
- 标记价格固定盘面中央；右侧等距价格刻度平滑移动，价格统一显示两位小数。
- 浏览器 EIP-1193 钱包连接；每笔交易由钱包签名，私钥不离开钱包。
- Hyperliquid activeAssetCtx WebSocket，10 秒 REST 快照补偿；账户每 5 秒查询。
- 全仓杠杆；IOC 市价开多、开空；reduceOnly 全量平仓；0.5% 滑点上限。
- 从真实持仓绘制开仓均价虚线，按标记价显示未实现盈亏（未扣手续费、资金费用）。
- X intent 分享，用户自行确认发布，不包含钱包地址。

## 运行
`python -m http.server 8080 --directory dist`

打开 http://localhost:8080，浏览器需安装 MetaMask/Rabby 等注入式钱包。移动端可用钱包内置浏览器。
交易账户需先在 Hyperliquid 完成必要的开户和充值。本站不实现充值、提现、资金托管、会员数据库或双向对冲持仓。

## 网络依赖
行情及账户直接请求 api.hyperliquid.xyz 或 api.hyperliquid-testnet.xyz。
签名客户端按需从 esm.sh 加载固定版本 @nktkas/hyperliquid 0.33.3 与 viem 2.37.3；加载失败会阻止提交并显示错误。
生产环境建议经依赖审计后将这些依赖本地打包，配置内容安全策略，并完成真实浏览器与测试网验收。

## 验证及限制
纯计算验证覆盖多空盈亏、数量截断及价格精度。未使用用户钱包，未执行真实下单或测试网签名。接口、签名模块的运行情况仍需在可访问 Hyperliquid 和 esm.sh 的用户浏览器验收。
网络不确定时不自动重试订单，提醒先刷新持仓核对。签名前市场、网络、钱包及持仓会检查；钱包签名等待期间价格仍可能变化，实际成交以交易所结果为准。
Hyperliquid 持仓为净持仓；本界面在相反持仓存在时要求先平仓。标记价用于居中显示和盈亏，成交价由订单簿决定。

官方接口文档：https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api
SDK：https://github.com/nktkas/hyperliquid


## 星海盘面与模拟交易
默认进入模拟模式，无需钱包，初始资金 1,000 USDC。独立浏览器本地账本包含模拟余额、单一净持仓和最近结算，支持重置资金。默认使用明确标注的合成行情，可在空仓时切换为 Hyperliquid 实时行情。合成行情不发起任何行情或交易网络请求。

动态盘面采用发光价格轨迹、缓慢漂移的粒子和背景光晕。最新价格点固定居中，历史报价按经过时间向左移动，右侧刻度显示两位小数。开仓均价虚线随价格基准移动。提供动效开关并尊重系统减少动态效果偏好。历史轨迹只记录页面收到的报价，不填造真实历史。

模拟撮合按当前显示价格，不计手续费、资金费或滑点。模拟逐仓保证金 = 开仓名义金额 / 杠杆；未实现盈亏 = 有符号持仓数量 ×（当前价 - 开仓均价）；平仓时结算到余额。加仓采用加权开仓均价。亏损达到该模拟仓位的保证金时自动平仓，最大损失限制为该保证金。这是体验用的简化模型，不复现 Hyperliquid 完整清算规则。

模拟持仓存在时禁止切换币种、行情来源或实盘，避免混用报价。X 分享会明确写明模拟交易、虚拟资金和行情来源。实时行情中断超过 15 秒时禁止模拟开仓和平仓；合成行情刷新页面后从保存的持仓报价恢复。

验证：模拟初始资金、多空结算、加权加仓、保证金限制、模拟强平和账本校验已通过；离线事件流程验证启动、开仓、报价、分享、平仓、重置全程不请求钱包或网络。未执行浏览器视觉测试。

## 全屏盘面
盘面工具栏提供全屏及还原按钮。优先使用浏览器 Fullscreen API，无法使用时自动铺满当前窗口。Esc 可退出。全屏左下角半透明浮窗展示当前交易对的未实现盈亏，模拟账户另显示累计已实现盈亏；数据过期会提示。还原时恢复原布局、滚动位置及键盘焦点。

## 盈亏状态反馈
全屏收益浮窗右上角在亏损时显示警报动画，盈利时显示金元宝动画。以两位小数可显示的收益为状态阈值；零收益、空仓及数据过期为中性。只在进入有收益状态或盈亏状态切换时播放提示音，两次提示间隔至少 6 秒。警报使用 Web Audio 合成，盈利使用浏览器英文语音说 Good；不支持语音合成时降级为双音提示。浏览器需首次用户交互解锁播放。
音效开关位于浮窗内，本浏览器记忆静音设置；关闭立即停止当前声音。退出全屏、隐藏页面或过期数据停止声音。动画遵守动效开关及系统减少动态效果偏好。
